# Bad Block

This is a separate local build based on the full Chromium uBlock Origin source. It enables additional annoyance/privacy lists and adds a local hardening filter list for advertising, analytics, telemetry, and link-tracking parameters. It is intentionally more aggressive and may cause some sites to break. Use the extension popup or dashboard to disable it for a site when necessary.

This is an unofficial local build. Upstream source and GPLv3 notices are retained in `LICENSE.txt`.
